# Website of Veronika Yakubu: CV version

Plain HTML, CSS and self-hosted fonts. No build step, no cookies, no external requests.
This version presents the CV, skills and projects only. It offers no services and shows no prices.

| File | Page |
|---|---|
| `index.html` | Home / CV (English) |
| `de.html` | Startseite / Lebenslauf (Deutsch) |
| `Veronika_Yakubu_CV.pdf` | CV download |
| `impressum.html` / `legal-notice.html` | Impressum (DE / EN) |
| `datenschutz.html` / `privacy-policy.html` | Datenschutzerklärung (DE / EN) |

## Update the live site (GitHub Desktop)
1. Extract this zip and open the `site_cv` folder.
2. In GitHub Desktop: Repository > Show in Explorer.
3. Copy everything from `site_cv` into the repository folder and choose to replace the existing files.
4. In GitHub Desktop: write a summary, Commit to main, Push origin.
5. Wait a minute, then open the site in a private browser window and press Ctrl+F5.

## Updating the CV later
Replace `Veronika_Yakubu_CV.pdf` with the new file (same name), commit and push. The repository is public, so the PDF is public.

## Search engines
Every page contains `<meta name="robots" content="noindex, nofollow">`, so search engines are asked not to list the site. Anyone with the link can still open it. When you want to be found in search, delete that one line from each page.
